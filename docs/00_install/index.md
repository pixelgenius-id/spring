The best way to install and use the Vexanium software is to build it from source:

* [Build Vexanium from Source](01_build-from-source/index.md)

## Supported Operating Systems

Vexanium currently supports the following operating systems:

1. Ubuntu 22.04 Jammy
2. Ubuntu 20.04 Focal

[[info | Note]]
| It may be possible to build and install Vexanium on other Unix-based operating systems. We gathered helpful information on the following page but please keep in mind that it is experimental and not officially supported. 

* [Build Vexanium on Other Unix-based Systems](01_build-from-source/00_build-unsupported-os.md)
